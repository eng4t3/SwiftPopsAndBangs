# Firmware ↔ Dashboard Interfaces (v2)

This is the contract between the firmware modules and the web dashboard. Change it only
together with every side that uses it.

## Source layout

| File | Responsibility |
| --- | --- |
| `swift_show_tuning/swift_show_tuning.ino` | Glue: Wi-Fi AP, HTTP `/`, WebSocket server (port 81), config protocol, NVS |
| `swift_show_tuning/engine_control.h/.cpp` | Tach ISR, RPM estimation, spark-cut patterns, launch control, limiter, decel pops, ghost cam |
| `swift_show_tuning/ota_update.h/.cpp` | Firmware updates: browser upload, GitHub online update, `/api/*` routes |
| `swift_show_tuning/web_ui.h` | Embedded dashboard (`INDEX_HTML`) |
| `swift_show_tuning/version.h` | `FW_VERSION` / `FW_VERSION_CODE` |

## WebSocket (`ws://192.168.4.1:81/`)

All messages are text frames.

### Firmware → dashboard

| Message | Meaning |
| --- | --- |
| `T:<rpm>,<cut>,<launchState>,<launchLeftMs>,<reason>` | Telemetry, ~30 Hz. `cut` 0/1. `launchState` 0 OFF, 1 ARMED, 2 HOLDING, 3 FIRED. `launchLeftMs` = remaining ARMED window. `reason` = `CutReason` below. Parsers must tolerate extra trailing fields and missing fields (old firmware sends only the first 3). |
| `CFG:{json}` | Current config, sent in reply to `GET_CONFIG`. Keys below plus `"fw":"x.y.z"`. |
| `ACK:SAVED` | Reply to `SAVE_FLASH` once the settings are written to flash. |

`reason` (`CutReason`): 0 none, 1 show button, 2 hands-free launch, 3 physical switch,
4 redline, 5 decel pops, 6 ghost cam, 7 bench test (engine stopped), 8 anti-flood lock
(cut requested but blocked by the timeout).

### Dashboard → firmware

| Message | Meaning |
| --- | --- |
| `BTN:1` | Show-mode 2-step button held. **Must be re-sent every 200 ms while held** (dead-man). The firmware releases the button on its own if no `BTN:1` arrives for 600 ms, or when the WebSocket disconnects. |
| `BTN:0` | Show-mode button released. |
| `LAUNCH:ARM` / `LAUNCH:DISARM` | Arm / cancel hands-free launch control. |
| `GET_CONFIG` | Request a `CFG:` message. |
| `SET_CFG:{json}` | Apply config (any subset of keys). Applied immediately, not saved. The firmware clamps values into the ranges below; it does not echo. Dashboard should throttle to ≤ 10 messages/s. |
| `SAVE_FLASH` | Persist the current config to NVS. Answered with `ACK:SAVED`. |

The dashboard treats the connection as dead if no message arrives for 1500 ms and reconnects.

### Config keys and ranges

| Key | Type | Range | Default |
| --- | --- | --- | --- |
| `armed` | bool | | `true` |
| `launchRpm` | int | 2500–6500 (step 50) | 3800 |
| `redlineRpm` | int | 3000–7500 (step 50) | 6200 |
| `decelPops` | bool | | `true` |
| `decelRpm` | int | 2500–6000 (step 50) | 3200 |
| `cutPattern` | int | 0 hard cut, 1 flames, 2 gunfire, 3 AK-47, 4 cannon | 1 |
| `maxCutSeconds` | float | 0 = unlimited, else 1.0–5.5 (UI slider 1.0–6.0, 6.0 = unlimited) | 3.0 |
| `ghostCam` | bool | | `false` |
| `launchDrop` | int | 300–1500 (step 50): RPM drop below `launchRpm` that counts as the clutch being released in hands-free launch | see `engineDefaultConfig()` |

## HTTP API (port 80, served by `ota_update.cpp`)

| Route | Meaning |
| --- | --- |
| `GET /` | Dashboard |
| `GET /update` | Minimal fallback upload page (works without JavaScript) |
| `POST /update[?md5=<hex>]` | Multipart firmware upload (field `update`). With `md5`, the image is verified before it is activated. `200` → device reboots. `4xx/5xx` → plain-text error. |
| `GET /api/info` | `{"fw","code","heap",…}` plus the update settings (`repo`, `branch`, `staSsid`, `tokenSet`, …) — see `ota_update.cpp` |
| `GET /api/ota/status` | Online-update progress (`state`, `progress`, `msg`, `latest`, …) |
| `POST /api/ota/*` | Online-update actions (Wi-Fi credentials, token, check, install) — see `ota_update.cpp` |

## Update manifest (`version.json` in the repository root)

Generated by the build script next to `firmware.bin`:

```json
{ "version": "2.0.0", "code": 20000, "size": 880000, "md5": "…", "built": "2026-09-24T12:00:00Z" }
```

`code` is compared against `FW_VERSION_CODE` to decide whether an update is available.
